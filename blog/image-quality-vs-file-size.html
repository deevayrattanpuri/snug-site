Quality versus file size: where the sweet spot actually is

The quality slider is not linear. Most of the file size lives in a range where you cannot see any difference.

Sizing 23 June 2026 ·6 min read

Every JPEG export offers a quality setting, usually 0 to 100. People assume it behaves like a volume knob. It does not. The relationship between that number and both file size and visible quality is deeply uneven, and knowing the shape of it saves a great deal of guesswork.

The shape of the curve

Roughly, for a typical photograph:

QualityRelative sizeWhat you can see
100Very largeNothing better than 95 — mostly wasted bytes
90–95LargeVisually indistinguishable from the original
75–85ModerateThe sweet spot — no visible loss in normal viewing
60–70SmallSlight softening in fine detail, fine for most uses
40–55Very smallVisible artefacts around edges and in smooth skies
Below 40TinyObvious blocking and colour banding

The step from 100 to 90 often removes half the file size and nothing you can perceive. The step from 50 to 40 removes far less and wrecks the picture. Almost nobody should be exporting at 100.

Where the artefacts show up first

Compression damage is not spread evenly. Look for it in:

  • Smooth gradients — clear skies become visible bands of colour
  • Hard edges — text and horizons get a faint halo
  • Fine repeating detail — hair, foliage and fabric turn mushy
  • Dark areas — shadows go blotchy before highlights do

If you are judging whether a setting is acceptable, look at those four things rather than the photo as a whole.

Content changes everything

A portrait against a plain wall and a photograph of a forest, at identical settings and dimensions, can differ in file size by a factor of three. The forest has more detail to describe. This is why a fixed quality setting produces wildly varying file sizes across a batch — and why working to a target file size is more predictable when there is a hard limit to meet.

Resizing is the cheaper lever

If a file is too big, halving the dimensions is almost always less visible than halving the quality. Fewer pixels at good quality looks clean; the same pixels at poor quality looks broken.

Reach for dimensions first and quality second.

A practical default

For photographs destined for a screen: resize to the dimensions you need, then save at quality around 80. You will be hard pressed to tell it from the original, and the file will be a fraction of the size.

If you are working to a hard limit instead, set the target file size and let the tool find the combination — then check the gradients and the edges before you send it.

The short version

Quality 80 is invisible and small. Quality 100 is enormous and no better. Resize before you drop quality.
