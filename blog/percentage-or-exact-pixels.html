Resize by percentage or by exact pixels?

One is for when you know the requirement. The other is for when you just need it smaller.

Sizing 9 June 2026 ·4 min read

Both arrive at a smaller photo. Which one you want depends entirely on whether somebody has given you a number.

Exact pixels: when there is a requirement

A form says 600 × 600. A platform says 1080 px wide. A print needs 1200 × 1800. In all of these, the number is the point, and typing it is the only sensible move.

The thing to watch is the aspect ratio. If your photo is 4:3 and the requirement is 1:1, typing 600 × 600 with the ratio unlocked will squash it. Crop to square first, then set the dimensions.

Percentage: when you just need smaller

No requirement, just a file that is too heavy to send. Scaling to 50% halves both dimensions and drops the file to roughly a quarter — without you having to know or care what the original dimensions were.

It is also the right tool for a mixed batch. A folder containing panoramas, portraits and screenshots has no single sensible pixel width. A fixed 1600 px would enlarge the screenshots and crop the panoramas awkwardly. 50% treats each one on its own terms.

A rough guide to percentages

ScaleFile size becomes roughlyGood for
75%About halfA gentle trim with no visible change
50%About a quarterThe everyday default for sharing
25%About a sixteenthThumbnails, quick previews, very tight limits

The relationship is quadratic, not linear: halving both width and height quarters the pixel count. This surprises people, and it is why 50% is usually far more than enough.

Do not enlarge

Scaling above 100% does not add detail. The software is inventing pixels by averaging their neighbours, which produces a softer, sometimes smeared result. If you need a bigger image, go back to a higher-resolution original rather than enlarging a small one.

And there is a third option

When the requirement is a file size rather than a dimension — "under 200 KB", with no mention of pixels — neither approach is ideal, because you would be guessing at the number that gets you there. Set the target file size instead and let the tool work out the dimensions.

The short version

Pixels when someone gave you a number. Percentage when they did not. Target file size when the number is in kilobytes.
